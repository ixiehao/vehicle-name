# 隐私声明 / Privacy Statement / 隱私聲明 / プライバシー方針

本文件说明本项目在**数据处理与隐私**方面的立场。各语言版本具有同等效力。

This document explains the project's stance on **data handling and privacy**. All language versions are equally valid.

本文件說明本專案在**資料處理與隱私**方面之立場。各語言版本具有同等效力。

本ファイルは、本プロジェクトの**データ取扱いとプライバシー**に関する方針を説明します。各言語版は同等の効力を有します。

## 1. 本项目收集哪些个人信息 / What Personal Data This Project Collects / 本專案收集哪些個人資料 / 本プロジェクトが収集する個人情報

**中文**:
本项目**不主动收集任何个人信息**。它是一个纯数据资料库(车型名称、术语、品牌名等),本身不包含、也不要求提供任何个人身份信息(PII)。您无需注册、无需登录即可下载和使用全部数据。

**English**:
This project does **not actively collect any personal information**. It is a pure data repository (model names, terms, brand names, etc.) and contains no personal data; no registration or login is required to download or use it.

**繁體中文**:
本專案**不主動收集任何個人資料**。其為純資料庫(車型名稱、術語、品牌名等),本身不含、亦不要求提供任何個人身分資訊(PII)。無需註冊、登入即可下載與使用全部資料。

**日本語**:
本プロジェクトは**個人情報を一切収集しません**。純粋なデータベース(車名・用語・ブランド名など)であり、個人を特定できる情報は含まれず、登録・ログインなしで全てのデータをダウンロード・利用できます。

## 2. 第三方平台 / Third-Party Platforms / 第三方平台 / 第三者のプラットフォーム

**中文**:
本项目可能托管于 GitHub 等第三方代码托管平台。您在这些平台上的活动(账号、IP、访问记录等)受该平台自身隐私政策约束,与本项目无关。若您通过 Issues/Pull Requests 提交内容,请勿在提交中包含任何个人敏感信息。

**English**:
This project may be hosted on third-party platforms such as GitHub. Your activity on those platforms (account, IP, access logs, etc.) is governed by their own privacy policies, not by this project. If you submit content via Issues/Pull Requests, please do not include sensitive personal information.

**繁體中文**:
本專案可能託管於 GitHub 等第三方程式碼託管平台。您於該等平台之活動(帳號、IP、存取紀錄等)受該平台自身隱私政策約束,與本專案無關。若透過 Issues/Pull Requests 提交內容,請勿包含任何個人敏感資訊。

**日本語**:
本プロジェクトは GitHub などの第三者のホスティングプラットフォームで公開される場合があります。それらのプラットフォーム上での活動(アカウント・IP・アクセスログなど)は、各プラットフォームのプライバシーポリシーに従い、本プロジェクトとは無関係です。Issues/Pull Requests で投稿する際は、個人の機微情報を含めないでください。

## 3. 数据来源与公开信息 / Data Sources & Public Information / 資料來源與公開資訊 / データソースと公開情報

**中文**:
本资料库的所有内容均整理自**公开信息**(车企官网、维基百科、标准文本、媒体报道等)。如果您认为某项内容侵犯了您的权益或涉及不当处理的信息,请通过 [SECURITY.md](SECURITY.md) 中的联系方式告知我们,我们将尽快核实与处理。

**English**:
All content in this database is compiled from **publicly available information** (brand websites, Wikipedia, standards, media, etc.). If you believe any entry infringes your rights or involves mishandled information, please contact us via the channels in [SECURITY.md](SECURITY.md); we will verify and act promptly.

**繁體中文**:
本資料庫之所有內容均整理自**公開資訊**(車廠官網、維基百科、標準文本、媒體報導等)。若您認為任何內容侵害您的權益或涉及不當處理之資訊,請透過 [SECURITY.md](SECURITY.md) 中之聯絡方式告知我們,我們將儘速核實與處理。

**日本語**:
本データベースの内容はすべて**公開情報**(メーカー公式サイト、Wikipedia、規格文書、報道など)から編集されています。万一、権利侵害や不適切な情報処理と思われる内容がある場合は、[SECURITY.md](SECURITY.md) に記載の連絡先までご連絡ください。速やかに確認し対応します。

## 4. 数据删除请求 / Data Deletion Requests / 資料刪除請求 / データ削除の要請

**中文**:
若您(作为信息权利人)要求删除资料库中的特定条目,请提供条目 ID 与理由。维护者将评估并在合理期限内处理;如无法判断权利人身份,维护者保留拒绝的权利。

**English**:
If you (as a rights holder) request removal of a specific entry, please provide the entry ID and reason. Maintainers will evaluate and act within a reasonable timeframe; requests from unidentified rights holders may be declined.

**繁體中文**:
若您(作為資訊權利人)要求刪除資料庫中之特定條目,請提供條目 ID 與理由。維護者將評估並於合理期限內處理;如無法判斷權利人身分,維護者保留拒絕之權利。

**日本語**:
(権利者として)特定の項目の削除を希望される場合は、項目 ID と理由をお知らせください。メンテナーが評価し、合理的な期間内に対応します。権利者であることが確認できない場合はお断りする場合があります。
