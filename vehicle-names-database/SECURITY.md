# 安全策略 / Security Policy

## 支持范围 / Supported Versions

| 版本 | 支持状态 |
|------|----------|
| 1.x (dist/ 数据产物) | 支持(与 data/ 源文件同步维护) |
| 0.x / 更早 | 不支持 |

| Version | Status |
|---------|--------|
| 1.x (dist/ artifacts) | Supported (kept in sync with data/ sources) |
| 0.x and earlier | Not supported |

## 报告漏洞 / Reporting a Vulnerability

本项目是**纯数据资料库**,不处理敏感数据,风险面极小。如您仍发现安全隐患(如:构建脚本漏洞、数据文件可被注入的恶意内容、第三方依赖问题等),请:

This project is a **pure data repository** with no sensitive data handling, so its attack surface is minimal. If you still find a security issue (e.g., a vulnerability in the build scripts, malicious content in data files, or third-party dependency issues), please:

1. **不要**在公开 Issues 中披露,直接联系我们。
   Do **not** disclose it in public Issues; contact us directly.
2. 提供复现步骤与影响范围。
   Provide reproduction steps and impact scope.
3. 我们会在确认后尽快处理并致谢。
   We will respond as soon as possible after confirmation and acknowledge your contribution.

联系方式(Contact):通过本仓库 GitHub Issues 私密提交,或发送邮件至仓库维护者邮箱(如有公开)。若维护者未公开邮箱,请在 Issues 中注明"安全相关(Security)"。

Contact: privately via GitHub Issues of this repository, or by email to the maintainer (if published). If no public email exists, open an Issue tagged "Security".

## 数据完整性 / Data Integrity

- 所有数据条目 `verified` 为 `pending` 的均列于 `pending_verification.json`,AI/程序在使用时应对其保持警惕。
- 构建产物 `dist/` 由 `scripts/build.py` 从 `data/` 生成,理论上可复现;若您发现 `dist/` 与 `data/` 不一致,请提交 Issue 或修正 PR。

- All entries with `verified: "pending"` are listed in `pending_verification.json` — treat them with caution.
- Build outputs under `dist/` are generated by `scripts/build.py` and are reproducible; report any inconsistency between `dist/` and `data/` via Issue or PR.
